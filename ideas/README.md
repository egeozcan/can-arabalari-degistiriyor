# Ideas: alternative development directions

These are alternative directions for further developing the game that were explored as full plans. Each plan was revised and scored by an evaluator agent on consistency, design and entertainment (0-10). The first plan to reach an average of 8.5 was implemented. The plans below did not reach the target and are kept here for later.

**Implemented instead:** "Yolcu Partisi v2: animal tower, guaranteed splash payoff, tight party" (`2-yolcu-partisi`, avg 8.5).

| Idea | Description | Best avg |
|---|---|---|
| [Sihirli Harita: Diyarlara Yolculuk](1-harita-diyarlar.md) | A world map after the Garage leads to themed lands (space, dinosaurs, seaside, ...), each with its own scenery, animals, gags and music. | 8.33 |
| [Sürpriz Makinesi ve Çıkartma Albümü](3-surpriz-makinesi-album.md) | Stars are saved in a piggy bank that feeds a gumball surprise machine giving car parts, stickers for an album, and joke capsules. | 8.07 |
| [Sürpriz Ustası: Anne-Babayla Birlikte](5-anne-baba-sihirbaz.md) | A play-together mode where a grown-up drops gags onto the road in front of the child's car from a hidden tray. | 8.03 |
| [Oto Yıkama ve Bakım Atölyesi](4-oto-yikama-bakim.md) | A hands-on car wash after the race: scrub off the real race mud, find a hidden sticker, rinse, dry and polish. | 7.83 |

Each file starts with the score history per round, followed by the latest plan text, copied verbatim.
